# Rahul Puppala — Portfolio

A responsive personal portfolio inspired by the supplied Asha.dev sample screenshot. Built with HTML, CSS and vanilla JavaScript.

## Project structure

```text
rahul-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── Rahul-Puppala-Profile.jpeg
    └── Rahul-Puppala-Resume.pdf
```

## Run locally

1. Open this folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

No npm installation or build command is required.

## Personal details

The portfolio uses the profile photo and resume already placed in `assets/`. The contact email, phone number, education, skills, certifications and project descriptions are based on the supplied resume/profile details. Confirm all contact details before publishing.

## Before publishing

- Replace the two project GitHub profile links with direct repository URLs when available.
- Confirm the phone number and email address.
- Test the site on mobile and desktop.

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. Import that repository into Vercel.
3. Choose **Other** as the framework preset.
4. Leave the build command empty and deploy as a static site.
